Ubuntu 22.04에서 PostgreSQL 18 및 pgvector 설치

Installing PostgreSQL 18 and pgvector on Ubuntu 22.04 — 공식 PGDG 저장소를 이용한 설치부터 벡터 검색 확장까지

1. 개요 Overview

이 문서는 Ubuntu 22.04 LTS (Jammy Jellyfish) 환경에 PostgreSQL 18을 설치하고, 벡터 유사도 검색(vector similarity search)을 지원하는 확장 모듈인 pgvector를 함께 구성하는 방법을 정리한 스터디 노트입니다. 대상 독자는 AI/RAG(Retrieval-Augmented Generation) 애플리케이션이나 임베딩 기반 검색 시스템을 위해 Postgres를 벡터 데이터베이스로 활용하려는 백엔드/인프라 엔지니어입니다.

왜 지금 PostgreSQL 18인가? Why PostgreSQL 18?
PostgreSQL 18은 2025년 9월 정식 릴리스되었으며, 비동기 I/O(AIO) 서브시스템 도입으로 순차/랜덤 읽기 성능이 크게 개선되고, B-tree 스킵 스캔(skip scan) 등 다양한 성능 개선이 포함되었습니다. 출처: PostgreSQL 공식 블로그 – PostgreSQL 18 Released

2. 핵심 개념 정의 Key Concepts

용어 정의
PGDG
PostgreSQL Global Development Group		 PostgreSQL 공식 apt 저장소를 관리하는 그룹. Ubuntu 기본 저장소보다 최신 메이저 버전을 제공
pgvector PostgreSQL에서 벡터(embedding) 데이터 타입과 코사인 유사도, L2 거리, 내적 등 벡터 연산 및 근사 최근접 이웃(ANN) 인덱스를 제공하는 오픈소스 확장
PGXS
PostgreSQL Extension Building Infrastructure		 C로 작성된 PostgreSQL 확장을 소스 빌드할 때 사용하는 공식 빌드 인프라. postgresql-server-dev-* 패키지에 포함
HNSW / IVFFlat pgvector가 지원하는 두 가지 ANN 인덱스 알고리즘. HNSW는 검색 정확도·속도가 우수하고, IVFFlat은 빌드가 빠르고 메모리 사용량이 적음

4. PostgreSQL 18 설치 Installing PostgreSQL 18

PGDG 저장소를 등록하는 방법은 두 가지입니다. 자동 스크립트를 이용하는 방법을 권장합니다.

방법 A. 자동 설정 스크립트 (권장) Automated Setup (Recommended)

PostgreSQL 팀이 제공하는 postgresql-common 패키지의 셋업 스크립트를 사용하면 OS 버전을 자동 감지하여 저장소를 구성합니다.

# 1) postgresql-common 설치
sudo apt update
sudo apt install -y postgresql-common

# 2) PGDG 저장소 자동 등록 스크립트 실행
sudo /usr/share/postgresql-common/pgdg/apt.postgresql.org.sh

# 3) 패키지 목록 갱신 및 PostgreSQL 18 설치
sudo apt update
sudo apt install -y postgresql-18

방법 B. 수동 설정 Manual Setup

스크립트를 신뢰하기 어려운 보안 정책 환경이거나 세부 제어가 필요한 경우 수동으로 구성할 수 있습니다.

# 1) 필수 패키지 설치
sudo apt install -y curl ca-certificates

# 2) PGDG 서명 키 다운로드
sudo install -d /usr/share/postgresql-common/pgdg
sudo curl -o /usr/share/postgresql-common/pgdg/apt.postgresql.org.asc \
  --fail https://www.postgresql.org/media/keys/ACCC4CF8.asc

# 3) DEB822 형식 소스 파일 생성 (Ubuntu 22.04 = jammy)
sudo tee /etc/apt/sources.list.d/pgdg.sources > /dev/null <<'EOF'
Types: deb deb-src
URIs: https://apt.postgresql.org/pub/repos/apt
Suites: jammy-pgdg
Architectures: amd64
Components: main
Signed-By: /usr/share/postgresql-common/pgdg/apt.postgresql.org.asc
EOF

# 4) 패키지 목록 갱신 및 설치
sudo apt update
sudo apt install -y postgresql-18
출처: PostgreSQL 공식 문서 – Linux downloads (Ubuntu)

설치 확인 Verify Installation

sudo systemctl status postgresql
sudo -u postgres psql -c "SELECT version();"

정상 설치 시 PostgreSQL 18.x가 포함된 버전 문자열이 출력됩니다. 서비스는 설치와 동시에 자동으로 활성화·시작됩니다.

5. pgvector 설치 Installing pgvector

pgvector는 Postgres 13 이상을 지원하며, 설치 방법은 apt 패키지 설치와 소스 빌드 두 가지가 있습니다.

출처: GitHub – pgvector/pgvector

방법 A. apt 패키지로 설치 (권장) APT Package (Recommended)

PGDG 저장소에는 PostgreSQL 각 메이저 버전에 대응하는 pgvector 패키지가 미리 빌드되어 제공됩니다. 버전 번호(18)를 설치한 PostgreSQL 버전에 맞춰 지정합니다.

sudo apt install -y postgresql-18-pgvector

방법 B. 소스에서 빌드 Build from Source

apt 패키지가 없는 환경이거나 최신 개발 버전을 사용하려는 경우 소스 빌드를 사용합니다.

# 1) 빌드 도구 및 PostgreSQL 서버 개발 헤더 설치
sudo apt install -y build-essential git postgresql-server-dev-18

# 2) 소스 클론 (안정 버전 태그 기준)
cd /tmp
git clone --branch v0.8.4 https://github.com/pgvector/pgvector.git
cd pgvector

# 3) 빌드 및 설치
make
sudo make install
주의 Note

postgresql-server-dev-18 패키지가 설치되어 있어야 pg_config를 통해 올바른 PostgreSQL 버전의 헤더/라이브러리 경로를 자동으로 찾습니다. 여러 버전의 PostgreSQL이 설치된 경우 PG_CONFIG 환경변수로 명시적으로 지정할 수 있습니다.

make PG_CONFIG=/usr/lib/postgresql/18/bin/pg_config
sudo make install PG_CONFIG=/usr/lib/postgresql/18/bin/pg_config

6. 확장 활성화 및 검증 Enable & Verify the Extension

pgvector는 데이터베이스마다 개별적으로 활성화해야 합니다. 슈퍼유저 또는 CREATE 권한이 필요합니다.

# 데이터베이스 접속
sudo -u postgres psql -d mydb

-- 확장 활성화
CREATE EXTENSION vector;

-- 설치 확인
\dx vector

간단한 사용 예시 Basic Usage Example

-- 3차원 벡터 컬럼을 가진 테이블 생성
CREATE TABLE items (
  id bigserial PRIMARY KEY,
  embedding vector(3)
);

-- 데이터 삽입
INSERT INTO items (embedding) VALUES
  ('[1,2,3]'), ('[4,5,6]'), ('[1,1,2]');

-- 코사인 거리 기준 최근접 이웃 3개 조회
SELECT id, embedding
FROM items
ORDER BY embedding <=> '[1,2,3]'
LIMIT 3;
거리 연산자 Distance Operators
연산자의미
<->L2(유클리드) 거리
<=>코사인 거리 (1 - 코사인 유사도)
<#>음의 내적 (negative inner product)

대규모 검색을 위한 인덱스 생성 Indexing for Large-Scale Search

-- HNSW 인덱스 (정확도·속도 우수, 권장)
CREATE INDEX ON items USING hnsw (embedding vector_cosine_ops);

-- 또는 IVFFlat 인덱스 (빌드 속도 빠름, 대량 데이터에 적합)
CREATE INDEX ON items USING ivfflat (embedding vector_cosine_ops)
WITH (lists = 100);

7. 자주 발생하는 문제 Common Issues

증상 원인 및 해결
could not open extension control file pgvector가 설치된 PostgreSQL 버전과 실제 실행 중인 서버 버전이 불일치. pg_lsclusters로 클러스터 버전 확인 후 재설치
permission denied to create extension 슈퍼유저 권한 필요. sudo -u postgres psql로 접속하거나 대상 유저에 필요한 권한 부여
여러 PostgreSQL 버전 충돌 Ubuntu는 동일 머신에 여러 메이저 버전 동시 설치 가능. pg_lsclusters, pg_ctlcluster로 버전별 클러스터 관리

8. 핵심 요약 Key Takeaways

  1. Ubuntu 22.04 기본 저장소는 PostgreSQL 14까지만 제공 — PostgreSQL 18을 쓰려면 반드시 PGDG 공식 저장소 등록 필요
  2. 자동 설정 스크립트(apt.postgresql.org.sh)가 가장 간단하고 실수가 적은 방법
  3. pgvector는 postgresql-18-pgvector apt 패키지로 손쉽게 설치 가능 — 소스 빌드는 최신 버전이 필요하거나 apt 패키지가 없을 때만 사용
  4. 확장은 데이터베이스 단위로 CREATE EXTENSION vector; 실행 필요 — 클러스터 전체가 아닌 개별 DB마다 활성화
  5. 대량 데이터는 HNSW 또는 IVFFlat 인덱스 필수 — 인덱스 없이는 순차 스캔으로 성능 저하
