1빈칸 추론 · 대화
다음 대화의 빈칸 ㉠에 들어갈 말로 가장 알맞은 것은?
みせの ひと : ゆかたは どれに しますか。 はる : ㉠
  • ①この ゆかたが じょうずです。
  • ②はい、そんな こと ありません。
  • ③どの ゆかたに します。
  • ④あおい ゆかたに します。
정답 : ④

「どれに しますか」도레니 시마스카 / 어느 것으로 하시겠습니까는 여러 가지 중 하나를 고르라고 묻는 표현입니다. 이에 대한 대답은 「〜に します」〜니 시마스 / 〜(으)로 하겠습니다 형태로 자신이 정한 것을 말합니다. 대화는 「유카타는 어느 것으로 하시겠습니까?」 → 「파란 유카타로 하겠습니다」가 됩니다.

선택지 해설

  1. 「じょうずだ」죠-즈다 / 잘하다는 사람의 솜씨를 칭찬하는 말이라 물건을 고르는 대답으로 쓸 수 없습니다.
  2. 「そんな こと ありません」손나 코토 아리마셍 / 그렇지 않습니다은 칭찬을 받았을 때의 겸손 표현이며, 앞에 「はい」하이 / 네가 오는 것도 어색합니다.
  3. 「どの」도노 / 어느는 질문할 때 쓰는 말이라 대답에 쓸 수 없고, 「〜に します」로 끝나 의문문도 아니어서 문장이 성립하지 않습니다.
  4. 「〜に します」로 자신이 고른 것을 밝히는 알맞은 대답입니다. → 정답
2틀린 것 찾기 · 지시어와 조사
다음 중 밑줄 친 부분의 쓰임이 옳지 않은 것은?
  • ①これは わたしの うちわです。
  • ②はるさんは うたが へたな です。
  • ③あの みこしは とても おおきいですね。
  • ④やまださんは にほんごが じょうずです。
정답 : ②

「じょうずだ・へただ」죠-즈다·헤타다 / 잘하다·서투르다 앞의 대상에는 조사 「が」를 쓰고, な형용사는 명사를 꾸밀 때만 「〜な」, 서술할 때는 「〜です」가 됩니다. ②는 꾸밀 명사가 없는데 「な」를 붙였으므로 「へたです」헤타데스 / 서투릅니다로 고쳐야 합니다.

선택지 해설

  1. 「これ」코레 / 이것는 사물을 가리키며 뒤에 명사 없이 단독으로 씁니다. 해석은 「이것은 제 부채입니다」.
  2. 서술 자리에 「な」를 붙일 수 없습니다. 「へたです」가 옳습니다. → 정답(옳지 않은 것)
  3. 「あの」아노 / 저는 뒤에 명사가 와야 하며 「あの みこし(저 가마)」로 바르게 쓰였습니다. 해석은 「저 가마는 아주 크네요」.
  4. 잘하는 대상에 「が」를 써서 「にほんごが じょうずです」니홍고가 죠-즈데스 / 일본어를 잘합니다로 바르게 쓰였습니다.
3선택형 · 문화
다음 설명에 해당하는 것으로 알맞은 것은?
일본의 3대 마쓰리 가운데 교토에서 열리는 축제이다.
  • ①てんじんまつり
  • ②かんだまつり
  • ③ぎおんまつり
  • ④はなび たいかい
정답 : ③

마쓰리「まつり」마쓰리 / 축제는 신사「じんじゃ」진쟈 / 신사를 중심으로 열리는 지역 축제입니다. 일본의 3대 마쓰리는 교토의 「ぎおんまつり」기온마쓰리 / 기온 축제, 오사카의 「てんじんまつり」텐진마쓰리 / 덴진 축제, 도쿄의 「かんだまつり」칸다마쓰리 / 간다 축제입니다.

선택지 해설

  1. 「てんじんまつり」는 오사카의 축제입니다.
  2. 「かんだまつり」는 도쿄의 축제입니다.
  3. 「ぎおんまつり」가 교토의 축제입니다. → 정답
  4. 「はなび たいかい」하나비 타이카이 / 불꽃놀이 대회는 여름에 열리는 불꽃놀이 행사를 가리키는 말로, 3대 마쓰리에 들어가지 않습니다.
📜 한국사Ⅰ. 일제 식민 통치와 민족 운동
1자료 분석 · 1910년대
다음 강령을 내세운 단체에 대한 설명으로 옳은 것은?
1. 일반 부호로부터 의연금을 받는 한편, 일본인이 불법 징수한 세금을 압수하여 무장을 준비한다. 2. 남북 만주에 사관 학교를 설치하고 인재를 양성하여 사관(士官)으로 채용한다. 7. 무력이 완비되는 대로 일본인 섬멸전을 단행하여 최후의 목적을 이룬다.
  • ①고종의 밀명을 받아 결성된 복벽주의 단체였다.
  • ②박상진 등이 주도하였으며 민주 공화제 국가 건설을 지향하였다.
  • ③3·1 운동을 계기로 상하이에서 조직되었다.
  • ④「조선 혁명 선언」을 활동 지침으로 삼았다.
정답 : ②

자료는 대한 광복회(1915)의 강령입니다. 박상진 등이 주도한 대한 광복회는 국권 회복 후 민주 공화제의 근대 국가를 세우려 하였고, 군자금을 모아 만주에 무관 학교를 세워 독립군을 기르려 하였으며 친일파 처단 활동도 벌였습니다.

선택지 해설

  1. 고종의 밀명을 받아 임병찬 등이 결성하고 복벽주의(고종의 복위)를 내세운 단체는 독립 의군부입니다.
  2. 대한 광복회는 박상진 중심의 공화주의 비밀 결사입니다. → 정답
  3. 대한 광복회는 3·1 운동 이전인 1915년 국내에서 조직되었습니다. 3·1 운동을 계기로 상하이에서 조직된 것은 대한민국 임시 정부입니다.
  4. 신채호가 쓴 「조선 혁명 선언」(1923)을 지침으로 삼은 단체는 김원봉이 조직한 의열단입니다.
2틀린 것 찾기 · 신간회
다음 강령을 채택한 단체에 대한 설명으로 옳지 않은 것은?
· 우리는 정치적·경제적 각성을 촉진함. · 우리는 단결을 공고히 함. · 우리는 기회주의를 일체 부인함.
  • ①정우회 선언과 비타협적 민족주의 세력의 연대 노력을 바탕으로 창립되었다.
  • ②전국에 140여 개의 지회를 둔 일제 강점기 최대 규모의 항일 단체로 성장하였다.
  • ③광주 학생 항일 운동이 일어나자 진상 조사단을 파견하였다.
  • ④일제가 치안 유지법을 제정하는 직접적인 계기가 되었다.
정답 : ④

자료는 신간회(1927)의 강령입니다. 신간회는 사회주의 진영의 정우회 선언(1926)과 이상재·안재홍 등 비타협적 민족주의 세력의 연대로 창립된 민족 유일당 운동의 결실로, 약 140개 지회와 4만여 회원을 거느린 최대 규모의 항일 단체였습니다.

선택지 해설

  1. 6·10 만세 운동 이후 형성된 민족 협동 전선의 공감대와 정우회 선언이 창립의 바탕이 되었습니다.
  2. 140여 개 지회·4만여 명의 회원 규모는 교과서에 명시된 사실입니다.
  3. 광주 학생 항일 운동(1929) 때 진상 조사단을 보내고 민중 대회를 추진하다 집행부가 구속되었습니다.
  4. 치안 유지법은 1925년에 제정되어 신간회 창립(1927)보다 앞섭니다. 오히려 치안 유지법의 탄압을 받던 사회주의 진영이 합법적 활동 공간을 찾으려 한 것이 신간회 창립의 배경이었습니다. → 정답(옳지 않은 것)
3순서 나열 · 무장 독립 전쟁
다음 사건을 일어난 순서대로 바르게 나열한 것은?
(가) 봉오동 전투 (나) 자유시 참변 (다) 미쓰야 협정 체결 (라) 한국광복군 창설
  • ①(가) → (나) → (다) → (라)
  • ②(가) → (다) → (나) → (라)
  • ③(나) → (가) → (라) → (다)
  • ④(다) → (가) → (나) → (라)
정답 : ①

(가) 봉오동 전투 1920. 6. → (나) 자유시 참변 1921 → (다) 미쓰야 협정 1925 → (라) 한국광복군 창설 1940 순입니다.

선택지 해설

  1. 1920 → 1921 → 1925 → 1940으로 바르게 배열되었습니다. → 정답
  2. 자유시 참변(1921)이 미쓰야 협정(1925)보다 먼저이므로 (다)와 (나)의 순서가 바뀌었습니다.
  3. 자유시 참변은 봉오동 전투·청산리 대첩 이후에 일어났고, 한국광복군 창설(1940)도 미쓰야 협정보다 뒤입니다.
  4. 미쓰야 협정(1925)은 3부의 활동을 탄압하기 위한 것으로 봉오동 전투(1920)보다 뒤입니다.
