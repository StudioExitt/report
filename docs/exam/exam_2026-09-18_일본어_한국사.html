다음 대화의 빈칸 ㉠, ㉡에 들어갈 조사가 바르게 짝지어진 것은?
ゆい : ミンスさんは うた㉠ じょうずですね。 ミンス : いいえ、そんな こと ありません。 ゆい : わたし㉡ うたが へたです。
  • ①㉠ が　㉡ は
  • ②㉠ を　㉡ が
  • ③㉠ は　㉡ を
  • ④㉠ に　㉡ は
정답 : ①

「じょうずだ」조-즈다 / 잘하다와 「へただ」헤타다 / 서투르다 앞에서 잘하고 못하는 대상을 나타낼 때는 반드시 조사 「が」를 씁니다. 「を」가 아님에 주의해야 합니다. ㉡은 앞 문장의 ミンス와 대비하여 '나는'이라고 화제를 내세우는 자리이므로 주제 조사 「は」가 알맞습니다. 전체 해석은 「유이 : 민수 씨는 노래를 잘하시네요. / 민수 : 아니요, 그렇지 않아요. / 유이 : 나는 노래를 못해요.」입니다.

선택지 해설

  1. ㉠은 능력의 대상을 나타내는 「が」, ㉡은 대비·주제를 나타내는 「は」입니다. → 정답
  2. 「うたを じょうずです」처럼 「を」는 쓸 수 없습니다. 「を」는 동사의 목적어에 붙습니다.
  3. ㉠에 「は」를 쓰면 「うたは じょうずですね」가 되어 문장 자체는 가능하지만, ㉡의 「わたしを」는 성립하지 않습니다.
  4. 「に」는 장소·시간·도착점 등을 나타내므로 능력의 대상에는 쓰지 않습니다.

참고 · 「が」를 쓰는 대표 표현

  1. にほんごが じょうずです / へたです 일본어를 잘합니다 / 못합니다
  2. りょうりが とくいです 요리를 잘합니다(자신 있습니다)
  3. すうがくが すきです / きらいです 수학을 좋아합니다 / 싫어합니다
2선택형 · 의복 어휘
다음 설명에 해당하는 말로 알맞은 것은?
기모노나 유카타를 입을 때 허리에 둘러 옷을 여미는 넓은 띠
  • ①ゆかた
  • ②げた
  • ③おび
  • ④うちわ
정답 : ③

「おび」오비 / 띠는 기모노나 유카타의 허리에 둘러 옷을 여미는 넓은 띠입니다. 6과에 나오는 전통 의상 관련 어휘를 정확히 구분해 두어야 합니다.

선택지 해설

  1. 「ゆかた」유카타는 면으로 만든 여름용 홑옷으로, 여름 축제나 불꽃놀이 때 입습니다.
  2. 「げた」게다는 유카타에 맞춰 신는 굽이 있는 나무 신발입니다.
  3. 「おび」오비 / 띠가 설명에 해당합니다. → 정답
  4. 「うちわ」우치와 / 부채는 유카타 차림에 함께 드는 둥근 부채입니다.

참고 · 전통 의상 관련 어휘

  1. きもの 기모노 — 격식을 갖춘 자리에서 입는 전통 의상
  2. ゆかた 유카타 — 면 소재의 여름용 홑옷 (옷깃은 반드시 왼쪽이 위)
  3. おび 오비 — 허리에 두르는 띠  /  げた 게다 — 나무 신발
3틀린 것 찾기 · 문장 종합
다음 중 문장이 옳지 않은 것은?
  • ①この みこしは とても おおきいですね。
  • ②あれは きれい ゆかたですね。
  • ③わたしは あの やたいに します。
  • ④はなびが ほんとうに きれいですね。
정답 : ②

「きれいだ」키레이다 / 예쁘다는 な형용사이므로 명사를 꾸밀 때 어미 「だ」를 「な」로 바꾸어 「きれいな ゆかた」예쁜 유카타라고 해야 합니다. 어간만 그대로 명사 앞에 붙일 수 없습니다.

선택지 해설

  1. 「この」 뒤에 명사 「みこし」가 왔고, 「おおきい」오오키이 / 크다는 い형용사라 「~いです」가 맞습니다.
  2. 「きれい ゆかた」가 아니라 「きれいな ゆかた」가 되어야 합니다. → 정답(옳지 않은 것)
  3. 「あの」 뒤에 명사 「やたい」가 왔고, 선택을 나타내는 「~に します」의 조사 「に」도 알맞습니다.
  4. 「きれいだ」를 서술어로 쓸 때는 「きれいです」가 되며, 「~ですね」로 공감을 나타냅니다.

참고 · な형용사와 い형용사의 명사 수식

  1. な형용사 : だ → な  (きれいだ → きれいな ゆかた / にぎやかだ → にぎやかな まつり)
  2. い형용사 : 기본형 그대로  (たのしい → たのしい はなび / おおきい → おおきい みこし)

제13조 본령은 조선인에 한하여 적용한다.
  • ①사이토 마코토 총독이 부임하여 이른바 '문화 통치'를 내세웠다.
  • ②헌병 경찰이 재판 없이 처벌할 수 있는 즉결 심판권을 행사하였다.
  • ③황국 신민 서사를 암송하게 하고 일본식 성명을 강요하였다.
  • ④치안 유지법을 제정하여 사회주의 운동을 탄압하였다.
정답 : ②

자료는 조선 태형령(1912)으로, 1910년대 무단 통치기에 조선인에게만 적용된 차별적 법령입니다. 이 시기에는 헌병 경찰제가 시행되어 헌병 사령관이 경무 총감을 겸하였고, 헌병 경찰은 정식 재판 없이 구류·벌금·태형을 부과할 수 있는 즉결 심판권을 행사하였습니다. 관리와 교사까지 제복을 입고 칼을 차게 하여 공포 분위기를 조성하였습니다.

선택지 해설

  1. 사이토 마코토의 '문화 통치'는 3·1 운동 이후인 1920년대의 일입니다.
  2. 헌병 경찰의 즉결 심판권은 1910년대 무단 통치의 대표적 특징입니다. → 정답
  3. 황국 신민 서사 암송과 일본식 성명 강요는 1930~40년대 민족 말살 통치기의 정책입니다.
  4. 치안 유지법은 1925년에 제정되었습니다.

참고 · 1910년대 무단 통치

  1. 조선 총독부 — 총독은 일본 육해군 대장 중 임명, 입법·사법·행정·군사권 장악
  2. 중추원 — 친일파로 구성된 자문 기구에 불과, 3·1 운동 전까지 한 번도 소집되지 않음
  3. 헌병 경찰제 — 조선 태형령(1912), 경찰범 처벌 규칙(1912), 언론·출판·집회·결사 자유 제한

정답 : ①

자료는 조선 형평사의 취지문입니다. 갑오개혁으로 신분제가 법적으로 폐지된 뒤에도 백정에 대한 사회적 차별이 이어지자, 1923년 진주에서 조선 형평사를 조직하고 차별 철폐를 요구하는 형평 운동을 펼쳤습니다. '형평(衡平)'은 저울처럼 평등하게 한다는 뜻입니다.

선택지 해설

  1. 계급 타파와 모욕적 칭호 폐지를 내건 형평 운동의 취지문입니다. → 정답
  2. 물산 장려 운동은 1920년 조만식 등이 평양에서 시작한 실력 양성 운동입니다.
  3. 민립 대학 설립 운동(1923)은 일제가 경성 제국 대학을 세워 무마하였습니다.
  4. 브나로드 운동(1931)은 문맹 퇴치와 농촌 계몽을 목표로 한 운동입니다.

참고 · 1920년대 사회·대중 운동

  1. 형평 운동(1923, 진주) — 백정 차별 철폐

  3. 원산 총파업(1929) — 일제 강점기 최대 규모의 노동 쟁의
  4. 근우회(1927) — 신간회의 자매 단체로 여성 운동 전개
3틀린 것 찾기 · 한중 연합 작전

  • ①만주 사변 이후 한국인과 중국인 사이에 한중 연합 전선이 형성되었다.
  • ②양세봉이 이끈 조선 혁명군은 중국 의용군과 연합하여 영릉가·흥경성 전투에서 승리하였다.
  • ③지청천이 이끈 한국 독립군은 중국 호로군과 연합하여 쌍성보·대전자령 전투에서 승리하였다.
  • ④조선 혁명군은 북만주를, 한국 독립군은 남만주를 주된 활동 무대로 삼았다.
정답 : ④

활동 지역이 서로 뒤바뀌었습니다. 조선 혁명군(양세봉)은 남만주의 국민부 산하 부대이고, 한국 독립군(지청천)은 북만주의 혁신 의회 계열 한국 독립당 산하 부대입니다. 1920년대 중반의 3부가 통합 운동을 거쳐 남만주의 국민부와 북만주의 혁신 의회로 재편되었고, 각각 조선 혁명군과 한국 독립군을 두었습니다.

선택지 해설

  1. 일제가 만주 사변(1931)을 일으키고 만주국을 세우자, 중국인의 반일 감정이 높아져 연합 전선이 가능해졌습니다.
  2. 조선 혁명군은 영릉가 전투(1932)와 흥경성 전투(1933)에서 승리하였습니다.
  3. 한국 독립군은 쌍성보 전투(1932), 동경성·대전자령 전투(1933)에서 승리하였습니다.
  4. 조선 혁명군은 남만주, 한국 독립군은 북만주가 맞습니다. → 정답(옳지 않은 것)

참고 · 1930년대 한중 연합 작전 정리

  2. 한국 독립군 — 지청천 · 북만주(혁신 의회) · 중국 호로군과 연합 · 쌍성보, 동경성, 대전자령
