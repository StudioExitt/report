1빈칸 추론 · 의문사
다음 대화의 빈칸 ㉠, ㉡에 들어갈 말이 바르게 짝지어진 것은?
みんす : この うちわ、㉠ ですか。 みせの ひと : 800えんです。 みんす : じゃ、この あかい うちわに します。 ゆい : わたしは しろいのと あおいの、㉡ に しようかな。
  • ①㉠ どれ　㉡ いくら
  • ②㉠ いくら　㉡ どこ
  • ③㉠ いくら　㉡ どちら
  • ④㉠ どちら　㉡ どれ
정답 : ③

㉠은 값을 묻는 자리이므로 「いくら」이쿠라 / 얼마가 들어갑니다. ㉡은 흰 것과 파란 것 두 가지 중에서 고르는 상황이므로 둘 중 하나를 고를 때 쓰는 「どちら」도치라 / 어느 쪽가 알맞습니다. 셋 이상 중에서 고를 때 쓰는 「どれ」도레 / 어느 것와 구별해야 합니다. 전체 해석은 「민수 : 이 부채, 얼마예요? / 가게 사람 : 800엔입니다. / 민수 : 그럼 이 빨간 부채로 할게요. / 유이 : 나는 흰 것과 파란 것, 어느 쪽으로 할까.」입니다.

선택지 해설

  1. ㉠에 「どれ」를 넣으면 값을 묻는 대답(800えんです)과 이어지지 않습니다.
  2. 「どこ」도코 / 어디는 장소를 묻는 말이라 물건을 고르는 자리에 쓸 수 없습니다.
  3. ㉠은 가격을 묻는 「いくら」, ㉡은 둘 중 선택이므로 「どちら」입니다. → 정답
  4. ㉠ 「どちらですか」는 값이 아니라 어느 쪽인지를 묻는 말이고, ㉡의 「どれ」는 셋 이상일 때 씁니다.
2선택형 · な형용사 서술
다음 대화의 밑줄 친 부분에 들어갈 말로 가장 알맞은 것은?
ゆい : この まつりは にぎやかですか。 みんす : いいえ、あまり ______ 。でも、とても きれいですよ。
  • ①にぎやかくないです
  • ②にぎやかじゃ ありません
  • ③にぎやかい ではないです
  • ④にぎやかな ありません
정답 : ②

「にぎやかだ」니기야카다 / 북적이다는 な형용사입니다. な형용사의 정중한 부정은 어간에 「じゃ ありません」(= 「では ありません」)을 붙여 만듭니다. 앞의 「あまり」아마리 / 그다지는 반드시 부정과 짝을 이루어 '그다지 ~않다'가 됩니다. 전체 해석은 「유이 : 이 축제는 북적이나요? / 민수 : 아니요, 그다지 북적이지 않아요. 그래도 아주 예뻐요.」입니다.

선택지 해설

  1. 「~くないです」는 い형용사의 부정형입니다(たのしい → たのしくないです). な형용사에는 쓸 수 없습니다.
  2. な형용사의 정중한 부정형으로 알맞습니다. 격식을 갖추면 「にぎやかでは ありません」이 됩니다. → 정답
  3. 「にぎやかい」라는 형태 자체가 없습니다. な형용사를 い형용사처럼 만든 잘못된 말입니다.
  4. 「な」는 명사를 꾸밀 때만 쓰는 형태라 서술어로 쓸 수 없습니다.
3틀린 것 찾기 · 대화 흐름
다음 중 대화가 자연스럽지 않은 것은?
  • ①A : にほんごが じょうずですね。　B : いいえ、まだまだです。
  • ②A : わあ、はなびが きれいですね。　B : ええ、ほんとうに きれいですね。
  • ③A : この ゆかた、どうですか。　B : とても かわいいですね。
  • ④A : うたが じょうずですね。　B : はい、わたしは うたが じょうずです。
정답 : ④

「じょうずだ」조-즈다 / 잘하다는 남을 칭찬할 때만 쓰는 말이라, 자신에게 쓰면 잘난 체하는 느낌을 줍니다. 또 일본어에서는 칭찬을 받으면 겸손하게 받아넘기는 것이 자연스럽습니다. 「いいえ、そんな こと ありません」이-에, 손나 코토 아리마셍 / 아니요, 그렇지 않아요, 「まだまだです」마다마다데스 / 아직 멀었어요, 「いえいえ」이에이에 / 아니에요 등으로 답합니다. 자신의 장기를 말할 때는 「とくいです」토쿠이데스 / 자신 있습니다를 씁니다.

선택지 해설

  1. 칭찬(じょうずですね)에 겸손(まだまだです)으로 답하는 가장 전형적인 흐름입니다.
  2. 「わあ」와- / 와아로 감탄하고 「~ですね」로 공감을 주고받는 자연스러운 대화입니다.
  3. 「どうですか」도-데스카 / 어떠세요?로 감상을 묻고 칭찬으로 답하는 자연스러운 흐름입니다.
  4. 칭찬에 「はい」로 맞장구치며 자신에게 「じょうずです」를 쓴 점이 모두 어색합니다. 「いいえ、そんな こと ありません。でも、うたは とくいです。」처럼 답해야 합니다. → 정답(자연스럽지 않은 것)
📜 한국사Ⅰ. 일제 식민 통치와 민족 운동
1자료 분석 · 대한민국 임시 정부
다음 회의가 열린 배경으로 옳지 않은 것은?
1923년 상하이에서 국내외 독립운동 단체의 대표 130여 명이 모여 독립운동의 새로운 방향을 논의하였다. 그러나 임시 정부를 고쳐 쓰자는 개조파와 새로 만들자는 창조파가 맞서면서 회의는 끝내 결렬되었다.
  • ①연통제와 교통국이 일제에 발각되어 임시 정부의 국내 연락망이 무너졌다.
  • ②외교 활동에 힘을 쏟았으나 뚜렷한 성과를 거두지 못하였다.
  • ③이승만이 국제 연맹에 위임 통치를 청원한 사실이 알려져 비판을 받았다.
  • ④중국 국민당이 임시 정부를 적극적으로 지원하기 시작하면서 노선 갈등이 커졌다.
정답 : ④

자료는 국민 대표 회의(1923)입니다. 연통제·교통국 조직망의 붕괴, 외교 노선의 성과 부진, 이승만의 위임 통치 청원에 대한 신채호 등의 비판이 겹치면서 소집되었으나, 개조파와 창조파의 대립으로 결렬되었습니다. 이후 이승만이 탄핵되고 박은식이 제2대 대통령에 올랐으며(1925), 곧 국무령 중심의 집단 지도 체제로 개헌하였습니다.

선택지 해설

  1. 연통제와 교통국이 발각되어 자금과 정보의 통로가 끊긴 것이 위기의 직접적 배경입니다.
  2. 파리 강화 회의와 구미 위원부를 통한 외교가 기대만큼의 성과를 내지 못했습니다.
  3. 신채호 등은 위임 통치 청원을 독립 정신에 어긋난다며 강하게 비판하였습니다.
  4. 중국 국민당의 본격적인 임시 정부 지원은 1932년 윤봉길 의거를 계기로 시작되었으므로, 1923년 국민 대표 회의의 배경이 될 수 없습니다. → 정답(옳지 않은 것)
2틀린 것 찾기 · 민족 문화 수호 운동
일제 강점기 한국사 연구에 대한 설명으로 옳지 않은 것은?
  • ①박은식은 국혼(國魂)을 강조하며 『한국통사』와 『한국독립운동지혈사』를 저술하였다.
  • ②백남운은 『조선상고사』를 저술하여 우리 역사를 '아(我)와 비아(非我)의 투쟁'으로 설명하였다.
  • ③정인보 등은 1930년대 중반 조선학 운동을 일으켜 『여유당전서』를 간행하였다.
  • ④이병도 등은 진단 학회를 조직하고 『진단학보』를 발행하여 실증 사학을 내세웠다.
정답 : ②

『조선상고사』에서 역사를 '아와 비아의 투쟁'으로 규정한 인물은 신채호입니다. 백남운은 유물 사관에 입각한 『조선사회경제사』를 써서, 우리 역사도 세계사의 보편적인 발전 단계를 거쳤음을 밝혀 식민 사관의 정체성론을 반박하였습니다.

선택지 해설

  1. 박은식은 나라는 형(形)이고 역사는 혼(魂)이라 하며 민족정신을 강조하였습니다.
  2. 『조선상고사』는 신채호의 저술이며, 백남운의 대표작은 『조선사회경제사』입니다. → 정답(옳지 않은 것)
  3. 조선학 운동은 정약용 서거 99주기를 계기로 실학을 재조명한 움직임입니다.
  4. 진단 학회(1934)는 문헌 고증을 통해 사실을 밝히는 실증 사학을 표방하였습니다.

참고 · 식민 사관과 이에 맞선 연구

  1. 타율성론 → 민족주의 사학(박은식·신채호)이 자주적 역사관으로 반박
  2. 정체성론 → 사회 경제 사학(백남운)이 보편적 발전 단계론으로 반박
  3. 당파성론 → 조선사 편수회의 『조선사』 편찬으로 뒷받침되던 논리
3자료 분석 · 학생 항일 운동
다음 격문이 발표된 운동에 대한 설명으로 옳은 것은?
검거된 학생을 즉시 우리 손으로 탈환하자. 경찰의 교내 진입을 절대 반대한다. 조선인 본위의 교육 제도를 확립하라. 식민지 노예 교육 제도를 철폐하라.
  • ①나주역에서 일어난 한·일 학생 간의 충돌을 계기로 전국으로 확산되었다.
  • ②순종의 인산일을 기해 학생들이 만세 시위를 벌였다.
  • ③고종의 서거와 2·8 독립 선언이 직접적인 계기가 되었다.
  • ④일제가 통치 방식을 이른바 '문화 통치'로 바꾸는 계기가 되었다.
정답 : ①

자료는 광주 학생 항일 운동(1929. 10.~11.)의 격문입니다. 나주역에서 일어난 한·일 학생 간 충돌과 이에 대한 일제 경찰의 편파적인 처리가 발단이 되어 광주에서 시작해 전국으로 번졌으며, 3·1 운동 이후 최대 규모의 항일 운동으로 평가됩니다. 신간회는 진상 조사단을 파견하고 민중 대회를 계획하였습니다.

선택지 해설

  1. 나주역 사건이 발단이 되어 학생들이 들고일어났고 전국으로 확산되었습니다. → 정답
  2. 순종의 인산일을 기해 일어난 것은 6·10 만세 운동(1926)입니다.
  3. 고종 서거와 2·8 독립 선언은 3·1 운동(1919)의 배경입니다.
  4. 일제가 '문화 통치'로 전환한 것은 3·1 운동의 결과입니다.
