🇯🇵 일본어6과 わあ、すごい! (선택·감탄·칭찬)
1빈칸 추론 · 대화
다음 대화의 빈칸 ㉠, ㉡에 들어갈 말이 바르게 짝지어진 것은?
みんす : わあ、はなびが ㉠ ですね。 ゆい : ええ、ほんとうに きれいですね。 みんす : すみません、この うちわは ㉡ ですか。 みせの ひと : ごひゃくえんです。
  • ①㉠ すごく ㉡ どれ
  • ②㉠ すごい ㉡ どちら
  • ③㉠ すごく ㉡ いくら
  • ④㉠ すごい ㉡ いくら
정답 : ④

㉠은 「〜ですね」 앞에서 감탄을 나타내는 자리이므로 い형용사의 기본형 「すごい」스고이 / 대단하다가 그대로 옵니다. ㉡은 값을 묻는 자리이므로 「いくら」이쿠라 / 얼마가 알맞습니다. 전체 해석은 「민수 : 와아, 불꽃놀이가 대단하네요. / 유이 : 네, 정말 예쁘네요. / 민수 : 실례합니다, 이 부채는 얼마예요? / 가게 사람 : 500엔입니다.」입니다.

선택지 해설

  1. 「すごく」스고쿠 / 매우는 뒤의 말을 꾸미는 부사형이라 「〜ですね」에 바로 붙지 않고, 「どれ」도레 / 어느 것는 값이 아니라 여럿 중 하나를 고를 때 씁니다.
  2. 「どちら」도치라 / 어느 쪽는 둘 중 하나나 방향을 물을 때 쓰는 말로 가격을 묻는 표현이 아닙니다.
  3. ㉡의 「いくら」는 맞지만 ㉠에 부사형 「すごく」가 와서 어색합니다.
  4. 감탄의 「すごいですね」 + 가격을 묻는 「いくらですか」로 모두 자연스럽습니다. → 정답
2틀린 것 찾기 · 〜に します
다음 중 밑줄 친 부분의 쓰임이 옳지 않은 것은?
  • ①わたしは あかい ゆかたに します。
  • ②やたいの たこやきを します。
  • ③のみものは おちゃに します。
  • ④どの げたに しますか。
정답 : ②

여러 가지 중에서 하나를 고르거나 정할 때는 「명사＋に します」니 시마스 / ~로 하겠습니다 형태를 씁니다. 조사 「を」를 쓴 「〜を します」는 '~을 하다'라는 뜻이 되어 음식을 선택하는 문맥에 맞지 않습니다.

선택지 해설

  1. 「빨간 유카타로 하겠습니다」로 선택 표현이 바르게 쓰였습니다.
  2. 선택을 나타내려면 「たこやきに します」타코야키니 시마스 / 다코야키로 하겠습니다가 되어야 합니다. → 정답(옳지 않은 것)
  3. 「마실 것은 녹차로 하겠습니다」로 자연스럽습니다.
  4. 「どの＋명사」로 물으며 「어느 게다로 하시겠어요?」라는 뜻이 됩니다.
3선택형 · 어휘
다음 설명에 해당하는 낱말로 알맞은 것은?
마쓰리 때 신을 모신다고 여겨 여러 사람이 어깨에 메고 거리를 도는 가마
  • ①みこし
  • ②やたい
  • ③はなび
  • ④おび
정답 : ①

「みこし」미코시 / 가마는 마쓰리에서 신이 타고 있다고 여겨 여러 사람이 함께 메고 도는 가마입니다.

선택지 해설

  1. 신을 모시고 메고 도는 가마를 가리킵니다. → 정답
  2. 「やたい」야타이 / 포장마차는 축제 때 음식을 파는 노점입니다.
  3. 「はなび」하나비 / 불꽃놀이는 여름 축제의 대표적인 볼거리입니다.
  4. 「おび」오비 / 띠는 기모노나 유카타의 허리에 두르는 띠입니다.
📜 한국사Ⅰ. 일제 식민 통치와 민족 운동
1자료 분석 · 토지 조사 사업
다음 규정에 따라 시행된 사업의 결과로 옳은 것은?
제4조 토지 소유자는 조선 총독이 정하는 기간 내에 주소·성명·소유지의 소재·지목·자번호·등급·면적 등을 임시 토지 조사 국장에게 신고하여야 한다.
  • ①농민의 관행적 경작권이 법으로 보장되었다.
  • ②총독부가 미신고 토지와 국공유지를 차지하여 동양 척식 주식회사 등에 헐값으로 넘겼다.
  • ③일본으로의 쌀 반출이 늘어나 국내 식량 사정이 나빠졌다.
  • ④한국인 회사의 설립이 총독의 허가를 받도록 바뀌었다.
정답 : ②

자료는 토지 조사령(1912)의 기한부 신고제 규정으로, 토지 조사 사업(1910~1918)의 근거였습니다. 지세의 공정한 부과와 근대적 소유권 확립을 명분으로 내세웠지만, 실제로는 식민 통치의 재정을 확보하고 일본인의 토지 획득을 돕는 데 목적이 있었습니다. 그 결과 총독부는 소유가 불분명한 토지와 국공유지를 차지해 동양 척식 주식회사와 일본인에게 싼값으로 넘겼습니다.

선택지 해설

  1. 지주의 소유권만 인정되었고 농민이 오랫동안 누리던 관행적 경작권은 부정되어, 기한부 계약 소작농이 크게 늘었습니다.
  2. 기한부 신고제를 이용해 총독부가 토지를 차지하고 이를 일본인·동척에 넘겼습니다. → 정답
  3. 쌀 반출 증가로 식량 사정이 나빠진 것은 1920년대의 산미 증식 계획의 결과입니다.
  4. 회사 설립을 허가제로 바꾼 것은 같은 시기의 회사령(1910)으로, 토지 조사 사업의 결과가 아닙니다.
2틀린 것 찾기 · 학생 항일 운동
(가), (나) 운동에 대한 설명으로 옳지 않은 것은?
(가) 1926년 순종의 인산일을 기회로 학생들이 격문을 뿌리며 만세를 외쳤다. (나) 1929년 나주역에서 일어난 한·일 학생 간 충돌을 계기로 광주에서 시작되어 전국으로 번졌다.
  • ①(가)는 사회주의 세력과 천도교 계열의 계획이 사전에 발각되어 학생들이 주도하게 되었다.
  • ②(가)를 계기로 민족 협동 전선에 대한 공감대가 형성되었다.
  • ③(나)의 확산을 막기 위해 신간회가 진상 조사단을 파견하였다.
  • ④(나)는 3·1 운동 이후 일어난 최대 규모의 항일 민족 운동이었다.
정답 : ③

(가)는 6·10 만세 운동(1926), (나)는 광주 학생 항일 운동(1929)입니다. 신간회는 광주 학생 항일 운동의 확산을 막으려 한 것이 아니라, 오히려 진상 조사단을 파견하고 민중 대회를 열어 운동을 전국으로 확산시키려 하였습니다.

선택지 해설

  1. 사회주의 세력과 천도교 계열의 준비가 사전에 발각되면서 학생들이 중심이 되어 전개되었습니다.
  2. 준비 과정에서 민족주의·사회주의 세력이 함께한 경험이 신간회(1927) 창립의 밑거름이 되었습니다.
  3. 신간회는 운동을 지원·확산하려 했으며, 민중 대회 추진은 일제의 탄압으로 좌절되었습니다. → 정답(옳지 않은 것)
  4. 광주 학생 항일 운동은 3·1 운동 이후 최대 규모의 항일 민족 운동으로 평가됩니다.
3빈칸 추론 · 1930~40년대 무장 단체
(가)~(다)에 들어갈 내용이 바르게 짝지어진 것은?
1938년 우한에서 조선 민족 전선 연맹이 (가) 를 창설하였는데, 이는 중국 관내에서 결성된 최초의 한인 무장 부대였다. 이후 다수의 대원이 화북으로 이동하여 1942년 (나) 으로 개편되었고, 김원봉이 이끌던 잔여 병력은 1942년 (다) 에 합류하였다.
  • ①(가) 조선 의용대 / (나) 조선 의용군 / (다) 한국광복군
  • ②(가) 조선 혁명군 / (나) 조선 의용군 / (다) 한국 독립군
  • ③(가) 조선 의용대 / (나) 한국 독립군 / (다) 한국광복군
  • ④(가) 한국광복군 / (나) 조선 의용대 / (다) 조선 의용군
정답 : ①

(가)는 조선 의용대(1938, 우한), (나)는 화북으로 이동한 대원들이 조선 독립 동맹 산하로 개편된 조선 의용군(1942), (다)는 김원봉이 이끈 잔여 병력이 합류한 한국광복군(1940년 충칭에서 창설, 총사령관 지청천)입니다. 이 합류로 광복군은 좌우 합작 부대의 성격을 띠게 되었습니다.

선택지 해설

  1. 조선 의용대 → 조선 의용군(화북) / 한국광복군(충칭)으로 나뉜 흐름이 바르게 연결되었습니다. → 정답
  2. 조선 혁명군은 1930년대 초 양세봉이 이끌며 남만주에서 영릉가·흥경성 전투를 벌인 부대로 시기와 지역이 다릅니다.
  3. 한국 독립군은 지청천이 이끌고 북만주에서 쌍성보·대전자령 전투를 치른 부대로, 화북 개편과 관계가 없습니다.
  4. 한국광복군은 1938년이 아니라 1940년 충칭에서 대한민국 임시 정부가 창설한 부대입니다.
