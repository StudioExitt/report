🇯🇵 일본어6과 わあ、すごい! (선택·감탄·칭찬)
1빈칸 추론 · 지시어
다음 대화의 빈칸 ㉠, ㉡에 들어갈 말로 알맞은 것은?
みんす : ゆいさん、㉠ ゆかたに しますか。 ゆい : わたしは ㉡に します。あおい ゆかたが すきです。
  • ①㉠ どれ ㉡ この
  • ②㉠ どの ㉡ これ
  • ③㉠ どの ㉡ この
  • ④㉠ どれ ㉡ それ
정답 : ②

㉠ 뒤에 명사 「ゆかた」가 이어지므로 명사를 수식하는 지시어 「どの」도노 / 어느를 씁니다. ㉡은 뒤에 조사 「に」가 바로 붙어 사물 자체를 가리키는 지시어가 필요하므로 「これ」코레 / 이것가 알맞습니다. 전체 해석은 「민수 : 유이 씨, 어느 유카타로 하겠어요? / 유이 : 저는 이것으로 하겠습니다. 파란 유카타를 좋아해요.」입니다.

선택지 해설

  1. 「どれ」도레 / 어느 것는 단독으로 쓰는 말이라 뒤에 명사 「ゆかた」를 바로 붙일 수 없습니다.
  2. 명사 앞에는 「どの＋명사」, 조사 앞에는 사물을 가리키는 「これ」가 와야 합니다. → 정답
  3. 「この」코노 / 이는 반드시 뒤에 명사가 따라와야 하므로 「この に します」처럼 쓸 수 없습니다.
  4. 「それ」소레 / 그것는 듣는 사람 쪽에 있는 것을 가리키므로, 자신이 고른 것을 말하는 ㉡에는 어울리지 않습니다.
2틀린 것 찾기 · 겸손 표현
칭찬에 대한 응답으로 어색한 것은?
  • ①A : にほんごが じょうずですね。 B : いいえ、そんな こと ありません。
  • ②A : うたが じょうずですね。 B : いえいえ、まだまだです。
  • ③A : りょうりが じょうずですね。 B : ええ、わたしは じょうずです。
  • ④A : えが じょうずですね。 B : ありがとうございます。でも、まだまだです。
정답 : ③

「じょうずだ」죠-즈다 / 잘하다는 남을 칭찬할 때만 쓰는 말입니다. 자기 자신에 대해서는 「とくいです」토쿠이데스 / 자신 있습니다를 쓰며, 칭찬을 받으면 겸손하게 답하는 것이 자연스럽습니다.

선택지 해설

  1. 「そんな こと ありません」손나 코토 아리마셍 / 그렇지 않습니다은 대표적인 겸손 응답입니다.
  2. 「まだまだです」마다마다데스 / 아직 멀었습니다 역시 칭찬을 받았을 때의 겸손한 대답입니다.
  3. 자기 자신에게 「じょうずです」를 쓴 데다 칭찬을 그대로 인정하고 있어 어색합니다. → 정답(어색한 것)
  4. 감사를 표한 뒤 겸손을 덧붙인 자연스러운 응답입니다.
3선택형 · 문화
일본의 마쓰리와 전통 의상에 대한 설명으로 옳은 것은?
  • ①일본의 3대 마쓰리는 교토의 ぎおんまつり, 오사카의 てんじんまつり, 도쿄의 かんだまつり이다.
  • ②ゆかた는 격식을 갖춘 자리에서 입는 비단 옷이다.
  • ③마쓰리는 주로 절(おてら)을 중심으로 열리는 행사이다.
  • ④기모노나 유카타를 입을 때 옷깃은 오른쪽이 위로 오게 여며 입는다.
정답 : ①

일본의 3대 마쓰리는 교토의 ぎおんまつり기온마쓰리, 오사카의 てんじんまつり덴진마쓰리, 도쿄의 かんだまつり간다마쓰리입니다.

선택지 해설

  1. 교토·오사카·도쿄의 세 축제가 일본의 3대 마쓰리로 꼽힙니다. → 정답
  2. 「ゆかた」유카타는 여름에 입는 면 소재의 홑옷이고, 격식을 갖춘 자리에는 「きもの」기모노를 입습니다.
  3. 마쓰리는 절이 아니라 신사(じんじゃ)진자를 중심으로 열리는 지역 축제입니다.
  4. 옷깃은 반드시 왼쪽이 위로 오게 여며야 하며, 오른쪽이 위로 오는 것은 장례 때의 방식입니다.
📜 한국사Ⅰ. 일제 식민 통치와 민족 운동
1자료 분석 · 의열단
다음 선언을 활동 지침으로 삼은 단체에 대한 설명으로 옳은 것은?
강도 일본을 쫓아내려면 오직 혁명으로써 할 뿐이니 …… 민중은 우리 혁명의 대본영(大本營)이다. 폭력은 우리 혁명의 유일한 무기이다.
  • ①김구가 상하이에서 조직하여 이봉창·윤봉길 의거를 이끌었다.
  • ②고종의 밀명을 받아 조직되어 국권 반환 요구서를 보내려 하였다.
  • ③김익상·김상옥·나석주 등이 단원으로 활동하며 식민 통치 기관을 공격하였다.
  • ④대한민국 임시 정부의 국내 비밀 행정 조직으로 연통제를 운영하였다.
정답 : ③

자료는 신채호가 1923년에 쓴 「조선 혁명 선언」으로, 의열단(1919, 만주 지린, 김원봉·윤세주)의 활동 지침이었습니다. 의열단은 5파괴·7가살을 목표로 김익상(조선 총독부, 1921), 김상옥(종로 경찰서, 1923), 나석주(동양 척식 주식회사, 1926) 등의 의거를 벌였습니다.

선택지 해설

  1. 이봉창·윤봉길 의거를 이끈 것은 김구가 1931년에 조직한 한인 애국단입니다.
  2. 고종의 밀명으로 조직되어 국권 반환 요구서를 보내려 한 것은 독립 의군부(1914, 임병찬)로, 복벽주의를 내세웠습니다.
  3. 세 사람 모두 의열단원으로 식민 통치 기관을 공격하였습니다. → 정답
  4. 연통제는 대한민국 임시 정부가 운영한 국내 비밀 행정 조직으로 의열단과는 관련이 없습니다.
2틀린 것 찾기 · 국민 대표 회의
1923년 국민 대표 회의를 전후한 대한민국 임시 정부에 대한 설명으로 옳지 않은 것은?
  • ①연통제와 교통국이 일제에 발각되어 조직이 크게 위축되었다.
  • ②이승만의 위임 통치 청원이 알려지면서 신채호 등이 강하게 비판하였다.
  • ③회의는 개조파와 창조파의 대립으로 성과 없이 결렬되었다.
  • ④회의 직후 이승만이 사임하고 김구가 곧바로 대통령으로 선출되었다.
정답 : ④

국민 대표 회의 결렬 이후 이승만은 탄핵되었고, 제2대 대통령으로는 박은식이 선출되었습니다(1925). 이후 임시 정부는 국무령 중심의 집단 지도 체제로 개헌하였습니다.

선택지 해설

  1. 연통제·교통국이 발각되어 국내와의 연락망과 자금줄이 끊긴 것이 회의 개최의 배경 중 하나였습니다.
  2. 이승만의 위임 통치 청원은 신채호 등으로부터 강한 비판을 받았습니다.
  3. 임시 정부를 고쳐 쓰자는 개조파와 새로 만들자는 창조파가 맞서 회의는 결렬되었습니다.
  4. 이승만은 사임이 아니라 탄핵되었고, 뒤를 이은 것은 김구가 아니라 박은식입니다. → 정답(옳지 않은 것)
3선택형 · 한국사 연구
(가)~(다) 인물과 저술·활동이 바르게 짝지어진 것은?
(가) 나라의 '혼(魂)'을 강조하며 『한국통사』와 『한국독립운동지혈사』를 저술하였다. (나) 유물 사관에 입각해 『조선사회경제사』를 써서 일제의 정체성론을 반박하였다. (다) 1934년 조직되어 『진단학보』를 펴내며 문헌 고증에 힘썼다.
  • ①(가) 신채호 / (나) 백남운 / (다) 조선어 학회
  • ②(가) 박은식 / (나) 백남운 / (다) 진단 학회
  • ③(가) 박은식 / (나) 정인보 / (다) 조선사 편수회
  • ④(가) 신채호 / (나) 정인보 / (다) 진단 학회
정답 : ②

(가)는 박은식, (나)는 백남운, (다)는 진단 학회입니다. 박은식은 나라의 '혼'을 강조한 민족주의 사학자이고, 백남운은 사회 경제 사학으로 식민 사관의 정체성론을 반박했으며, 진단 학회는 실증 사학을 대표하는 학술 단체입니다.

선택지 해설

  1. 신채호는 『조선상고사』·『조선사연구초』를 남겼고, 조선어 학회는 한글 맞춤법 통일안 제정과 『조선말 큰사전』 편찬을 추진한 국어 연구 단체입니다.
  2. 세 사람·단체의 저술과 학풍이 모두 바르게 짝지어졌습니다. → 정답
  3. 정인보는 1930년대 중반 조선학 운동을 이끌며 실학을 연구한 인물이고, 조선사 편수회는 식민 사관에 따라 『조선사』를 편찬한 일제의 기관입니다.
  4. (가)의 『한국통사』는 신채호가 아니라 박은식의 저술이며, (나)의 유물 사관 연구자는 정인보가 아니라 백남운입니다.
