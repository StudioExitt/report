🇯🇵 일본어6과 わあ、すごい! (선택·감탄·칭찬)
1빈칸 추론 · 조사
다음 대화의 빈칸 ㉠, ㉡에 공통으로 들어갈 조사로 알맞은 것끼리 짝지어진 것은?
みんす : ゆいさんは うた ㉠ じょうずですね。 ゆい : いいえ、まだまだです。みんすさんこそ にほんご ㉡ とても じょうずですね。
  • ①㉠ を　㉡ を
  • ②㉠ が　㉡ が
  • ③㉠ は　㉡ を
  • ④㉠ が　㉡ を
정답 : ②

「じょうずだ」조-즈다 / 잘하다와 「へただ」헤타다 / 서투르다 앞에서 잘하는 대상을 나타낼 때는 「を」가 아니라 「が」를 씁니다. 전체 해석은 「민수 : 유이 씨는 노래를 잘하시네요. / 유이 : 아니에요, 아직 멀었어요. 민수 씨야말로 일본어를 아주 잘하시네요.」입니다.

선택지 해설

  1. 한국어로는 '노래를 잘한다'이지만 일본어에서는 목적격 조사 「を」를 쓰지 않습니다.
  2. 두 곳 모두 「が」를 써야 합니다. → 정답
  3. 「は」는 주제를 나타내는 조사로, 이미 「ゆいさんは」가 주제로 쓰였으므로 겹쳐 쓰면 어색합니다.
  4. ㉠은 맞지만 ㉡에도 똑같이 「が」를 써야 합니다.
2선택형 · 대화 완성
다음 대화의 밑줄 친 부분에 들어갈 말로 가장 알맞은 것은?
みせの ひと : いらっしゃいませ。 みんす : すみません。この うちわは ______ 。 みせの ひと : 500えんです。 みんす : じゃ、これに します。
  • ①どれですか
  • ②じょうずですか
  • ③いくらですか
  • ④そんな こと ありません
정답 : ③

대답이 「500えんです」고햐쿠엔데스 / 500엔입니다이므로 값을 묻는 「いくらですか」이쿠라데스카 / 얼마입니까?가 알맞습니다. 마지막 「これに します」코레니 시마스 / 이것으로 하겠습니다는 선택·결정을 나타내는 표현입니다.

선택지 해설

  1. 「どれですか」도레데스카 / 어느 것입니까?는 여럿 중 하나를 가리켜 물을 때 쓰므로 가격 대답과 이어지지 않습니다.
  2. 「じょうずですか」는 솜씨를 묻는 말이라 물건에는 쓰지 않습니다.
  3. 값을 묻는 표현으로 대답과 자연스럽게 이어집니다. → 정답
  4. 「そんな こと ありません」손나 코토 아리마센 / 그렇지 않습니다은 칭찬을 받았을 때의 겸손한 응답입니다.
3틀린 것 찾기 · 어휘와 문화
다음 중 단어의 뜻풀이가 옳지 않은 것은?
  • ①みこし — 마쓰리 때 여럿이 어깨에 메고 나르는 가마
  • ②やたい — 축제 때 음식 등을 파는 포장마차
  • ③おび — 유카타를 입을 때 발에 신는 나막신
  • ④はなび — 여름 축제에서 즐겨 보는 불꽃놀이
정답 : ③

「おび」오비는 기모노나 유카타의 허리에 두르는 띠입니다. 발에 신는 나막신은 「げた」게타 / 게다입니다.

선택지 해설

  1. 「みこし」미코시 / 가마는 신을 태워 마을을 돈다고 여겨 여럿이 메고 나릅니다.
  2. 「やたい」야타이 / 포장마차는 마쓰리 거리에 늘어서 먹을거리와 놀거리를 팝니다.
  3. 「おび」는 허리띠이고, 나막신은 「げた」입니다. → 정답(옳지 않은 것)
  4. 「はなび」하나비 / 불꽃놀이는 여름 마쓰리의 대표적인 볼거리입니다.
📜 한국사Ⅰ. 일제 식민 통치와 민족 운동
1자료 분석 · 1910년대 경제 수탈
다음 법령이 시행되던 시기에 있었던 사실로 옳은 것은?
제1조 회사의 설립은 조선 총독의 허가를 받아야 한다. 제5조 회사가 본령이나 본령에 따른 명령을 어겼을 때 조선 총독은 사업의 정지·금지 또는 회사의 해산을 명할 수 있다.
  • ①헌병 경찰이 즉결 심판권을 행사하였고, 한국인에게만 조선 태형령이 적용되었다.
  • ②치안 유지법을 제정하여 사회주의 운동과 독립운동을 탄압하였다.
  • ③국가 총동원법에 근거하여 국민 징용령을 시행하였다.
  • ④산미 증식 계획을 추진하여 늘어난 쌀보다 더 많은 양을 일본으로 실어 갔다.
정답 : ①

자료는 회사령(1910)으로, 1910년대 무단 통치기에 시행되었습니다(1920년 신고제로 전환되며 폐지). 같은 시기 일제는 헌병 경찰제를 실시해 헌병 경찰에게 즉결 심판권을 주었고, 조선 태형령(1912)을 만들어 한국인에게만 태형을 가하였습니다. 토지 조사 사업(1910~1918)도 이 시기의 일입니다.

선택지 해설

  1. 헌병 경찰제와 조선 태형령은 모두 1910년대 무단 통치기의 일입니다. → 정답
  2. 치안 유지법은 1925년, 이른바 '문화 통치' 시기에 제정되었습니다.
  3. 국가 총동원법은 1938년으로, 중일 전쟁 이후 전시 동원 체제기의 일입니다.
  4. 산미 증식 계획은 1920년부터 추진되었습니다.
2틀린 것 찾기 · 실력 양성 운동
1920년대 실력 양성 운동에 대한 설명으로 옳지 않은 것은?
  • ①물산 장려 운동은 조만식 등이 평양에서 시작하여 '내 살림 내 것으로'를 내세웠다.
  • ②물산 장려 운동은 물가만 올려 자본가의 이익을 늘린다는 사회주의 계열의 비판을 받았다.
  • ③민립 대학 설립 운동은 조선 민립 대학 기성회를 중심으로 모금 운동을 전개하였다.
  • ④일제는 민립 대학 설립 요구를 받아들여 경성 제국 대학의 설립과 운영을 한국인에게 맡겼다.
정답 : ④

일제는 민립 대학 설립 운동이 확산되자 경성 제국 대학을 세워 여론을 무마하였을 뿐, 한국인에게 설립·운영을 맡기지 않았습니다. 경성 제국 대학은 일제가 세운 관립 대학으로 한국인 입학은 매우 제한되었습니다.

선택지 해설

  1. 물산 장려 운동은 1920년 조만식 등이 평양에서 시작해 전국으로 퍼졌습니다.
  2. 수요는 늘었으나 생산이 따르지 못해 물가가 올랐고, 사회주의자들은 자본가·상인의 이익만 늘린다고 비판하였습니다.
  3. 1923년 조선 민립 대학 기성회를 세우고 '한민족 1천만이 한 사람 1원씩'을 내걸며 모금하였습니다.
  4. 경성 제국 대학은 일제가 운동을 무마하기 위해 세운 관립 대학입니다. → 정답(옳지 않은 것)
3선택형 · 종교계의 민족 운동
일제 강점기 종교계의 활동에 대한 설명으로 옳은 것은?
  • ①대종교 — 만주에서 중광단을 조직하였고, 이는 뒷날 북로 군정서로 이어졌다.
  • ②천도교 — 박중빈이 저축과 근로를 강조하는 새 생활 운동을 전개하였다.
  • ③원불교 — 한용운이 조선 불교 유신회를 만들어 사찰령 폐지를 주장하였다.
  • ④천주교 — 주기철 등이 신사 참배를 거부하다가 순교하였다.
정답 : ①

나철이 창시한 대종교는 만주로 근거지를 옮겨 중광단을 조직하였고, 3·1 운동 이후 이를 북로 군정서로 개편하여 김좌진의 지휘 아래 청산리 대첩에서 활약하였습니다.

선택지 해설

  1. 대종교 → 중광단 → 북로 군정서로 이어집니다. → 정답
  2. 새 생활 운동을 전개한 박중빈은 원불교를 창시한 인물입니다. 천도교는 3·1 운동을 주도하고 제2의 독립 선언(1922)을 계획했으며 『개벽』·『신여성』 등을 발행하였습니다.
  3. 조선 불교 유신회를 만들어 사찰령 폐지를 주장한 한용운은 불교계 인물입니다.
  4. 신사 참배를 거부하다 순교한 주기철은 개신교 목사입니다. 천주교는 만주에서 의민단을 조직해 무장 투쟁에 참여하였습니다.
