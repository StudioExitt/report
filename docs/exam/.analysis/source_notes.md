## 1) 고등학교_일본어_2026-08-22_자습서_평가문제집_학습정리.pdf — 6과 (p.12 기준, PDF page idx 11~12)
6과 わあ、すごい! — 선택·감탄·칭찬 (96쪽)
- 의사소통: 선택 どれに しますか / これに します · 감탄 わあ、すごい! · 칭찬 にほんごが じょうずですね
  · 겸손 いいえ、そんな こと ありません / まだまだです / いえいえ
- 문법: 〜に します(선택·결정) / これ・それ・あれ・どれ(사물) / この・その・あの・どの+명사
  / 〜が じょうずだ・へただ(조사 が) / 〜ですね(공감·확인) / な형용사(명사수식 な, 서술 だ·です)
- 주의: じょうず는 남을 칭찬할 때만. 자신은 とくいです
- 어휘: まつり 축제 / はなび 불꽃놀이 / みこし 가마 / やたい 포장마차 / ゆかた / きもの
  / おび 띠 / げた 게다 / うちわ 부채 / すごい 대단하다 / きれいだ 예쁘다 / じょうずだ 잘하다
  / へただ 서투르다 / たのしい 즐겁다 / にぎやかだ 북적이다 / どれ / どちら / いくら 얼마
- 문화: まつり는 신사(じんじゃ) 중심 지역 축제. 3대 마쓰리 = 교토 ぎおんまつり, 오사카 てんじんまつり,
  도쿄 かんだまつり. 여름=ゆかた(면), 격식=きもの. 옷깃은 반드시 왼쪽이 위.

### 2. 무단 통치와 수탈 체제 (1910년대)
- 조선 총독부: 총독은 일본 육해군 대장 중 임명, 입법·사법·행정·군사권 장악, 일왕 직속.
  중추원 = 자문 기구에 불과, 친일파 구성, 3·1 운동 전까지 한 번도 소집 안 됨.
- 헌병 경찰제: 헌병 사령관=경무 총감. 즉결 심판권(구류·벌금·태형). 조선 태형령(1912, 조선인만 적용).
  경찰범 처벌 규칙(1912). 관리·교사 제복+칼. 언론·출판·집회·결사 자유 제한. 우민화 교육(보통·실업 위주).
- 토지 조사 사업(1910~1918): 명분=지세 공정 부과·근대적 소유권 확립, 실제=재정 확보·일본인 토지 획득.
  기한부 신고제 → 총독부가 소유 불분명 토지·국공유지 차지 → 동양 척식 주식회사·일본인에 헐값 이전.
  지주 소유권만 인정, 농민 관행적 경작권 부정 → 기한부 계약 소작농 증가.
- 회사령(1910): 회사 설립 총독 허가제, 총독 명령으로 해산 가능. 어업·광업 허가제.
  철도·도로·항만·통신 정비(일본 상품 유통·자원 반출 목적) → 한국인 산업 활동 위축.
### 3. 민족 분열 통치와 경제 수탈 확대 (1920년대)
- '문화 정치'(3·1 운동 계기, 사이토 마코토): 문관 총독 임명 가능하게 관제 개정했으나 문관 총독 한 명도 없음.
  헌병경찰제→보통경찰제이나 경찰 관서·인원·비용 대폭 증가. 치안 유지법(1925) 제정.
  도 평의회·부면 협의회 = 의결권 없는 자문 기구. 조선일보·동아일보 창간되나 사전 검열·삭제·정간·폐간.
  학교 증설·수업 연한 확대하나 취학률 낮음. 본질 = 친일 세력 양성, 민족 분열 통치.
- 산미 증식 계획(1920~1934): 배경=1차대전기 일본 공업화→쌀값 폭등·쌀 부족.
  개간·품종 개량·비료·수리 시설 → 생산 증가하나 목표 미달. 반출은 예정대로 → 식량 사정 악화.
  비료 대금·수리 조합비 농민 전가 → 자작농이 소작농·화전민·토막민으로 전락, 만주·연해주·일본 이주.
- 회사령 폐지(1920, 신고제 전환), 일본 상품 관세 대부분 철폐(1923) → 한국인 기업 타격.
### 4. 민족 말살 통치와 전시 동원 체제 (1930~40년대)
- 내선일체·일선동조론·황국 신민화. 황국 신민 서사 암송, 궁성 요배, 신사 참배 강요,
  한국어 교육 금지, 소학교→'국민학교'(1941 제3차 조선교육령), 일본식 성명 강요(거부 시 불이익).
  조선일보·동아일보 폐간, 조선어 학회 사건(1942, 치안 유지법 적용).
- 식민지 공업화: 일본 독점 자본 진출, 중화학·광업, 북부 편중. 흥남 조선 질소 비료 공장(1927, 노구치).
- 남면북양: 대공황 후 서구 보호무역으로 어려운 일본 방직 자본가에 값싼 원료 공급 → 남부 면화, 북부 양.
- 병참 기지화(중일 전쟁 이후): 군수 산업 중심 개편, 소비재 산업 위축, 지역 간 산업 불균형 심화.
  인천 육군 조병창(1939).
- 국가 총동원법(1938): 지원병제·학도 지원병제·징병제, 국민 징용령, 일본군 '위안부',
  여자 정신 근로령. 공출(쌀·놋그릇·종), 배급제. 국민정신 총동원 운동 + 애국반.
