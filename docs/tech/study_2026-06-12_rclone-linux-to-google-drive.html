1. rclone이란? What is rclone?

rclone은 클라우드 스토리지와 로컬 파일시스템 사이의 파일을 동기화·복사·이동할 수 있는 오픈소스 CLI 도구입니다. "클라우드 스토리지용 rsync"라고 불리기도 합니다. rclone is an open-source CLI tool for syncing, copying, and moving files between cloud storage and local filesystems — often called "rsync for cloud storage".

Google Drive, S3, Dropbox, OneDrive 등 70개 이상의 클라우드 스토리지를 지원합니다.

특징 Feature 설명 Description
크로스 플랫폼 Cross-platform Linux, macOS, Windows 모두 지원
암호화 Encryption 서버 측/클라이언트 측 암호화 지원
체크섬 검증 Checksum verification MD5/SHA-1 기반 파일 무결성 검사
대역폭 제어 Bandwidth throttle --bwlimit으로 업로드 속도 제한 가능
병렬 전송 Parallel transfers 다수 파일 동시 업로드로 속도 향상

3. Google Drive 연결 설정 Configure Google Drive Remote

rclone은 remote(리모트)라는 개념으로 클라우드 스토리지 연결을 관리합니다. rclone manages cloud storage connections via remotes.

STEP 1

설정 마법사 실행 Run the configuration wizard

rclone config
STEP 2

새 리모트 추가 Add a new remote

No remotes found, make a new one?
n) New remote
...
n/s/q> n

# 리모트 이름 입력 (예: gdrive)
name> gdrive
STEP 3

스토리지 유형 선택 Select storage type

# 목록에서 Google Drive 번호 선택 (보통 17~20번 사이, 버전마다 다름)
Storage> drive
# 또는 숫자로 선택: Storage> 17
STEP 4

OAuth 인증 OAuth Authentication

# client_id, client_secret은 공백(엔터)으로 기본값 사용 가능
# (개인 사용 시 기본값으로도 충분)
client_id> [Enter]
client_secret> [Enter]

# 접근 범위 선택
scope> 1   # Full access to all files

# 브라우저 인증 (GUI 환경 없는 서버는 N)
Use auto config?
y) Yes (default)   # 로컬 브라우저가 있을 때
n) No              # 헤드리스 서버일 때
y/n> n
헤드리스 서버 (Headless Server)의 경우:
n을 선택하면 rclone이 인증 URL을 출력합니다. 로컬 PC에서 해당 URL을 브라우저로 열어 인증 후 나타나는 코드를 서버에 붙여넣으면 됩니다.
If running on a headless server: select n, open the given URL on your local browser, authenticate, then paste the verification code back in the terminal.
STEP 5

설정 완료 확인 Confirm configuration

rclone lsd gdrive:
# Google Drive의 폴더 목록이 나오면 정상

4. 주요 명령어 Key Commands

명령어 Command 설명 Description 특징 Notes
rclone copy 소스 → 목적지 복사 Copy source to destination 목적지에만 있는 파일은 삭제 안 함
rclone sync 소스와 목적지를 동기화 Sync source to destination 목적지에만 있는 파일 삭제됨 ⚠️
rclone move 소스 파일을 이동 Move source files 전송 후 소스 파일 삭제
rclone ls 파일 목록 조회 List files 재귀적으로 모든 파일 나열
rclone lsd 디렉토리 목록 조회 List directories 폴더만 표시
rclone check 양쪽 파일 비교 Compare files 실제 전송 없이 차이만 확인
rclone mount 클라우드를 로컬에 마운트 Mount cloud as local filesystem FUSE 기반 마운트
⚠️ sync vs copy 주의사항
rclone sync는 소스에 없는 파일을 목적지에서 삭제합니다. 처음 테스트할 때는 반드시 --dry-run 플래그를 함께 사용하세요.
rclone sync deletes files at the destination that don't exist at the source. Always test with --dry-run first.

5. 동기화 실행 Running Sync

기본 동기화 Basic sync

# 형식: rclone sync <소스> <목적지>
# Format: rclone sync <source> <destination>

# /home/user/data 를 Google Drive의 backup 폴더로 동기화
rclone sync /home/user/data gdrive:backup

드라이런 먼저 확인 Dry run first

# --dry-run: 실제 전송 없이 어떤 파일이 변경될지 미리 확인
# --dry-run: simulate the operation without actually transferring files
rclone sync /home/user/data gdrive:backup --dry-run -v

진행률 표시와 함께 실행 Run with progress output

# --progress: 실시간 전송 진행률 표시
rclone sync /home/user/data gdrive:backup --progress

# 자세한 로그와 함께
rclone sync /home/user/data gdrive:backup -v --progress

특정 파일/패턴 제외 Exclude files/patterns

# .log 파일 제외
rclone sync /home/user/data gdrive:backup --exclude "*.log"

# 특정 디렉토리 제외
rclone sync /home/user/data gdrive:backup --exclude "tmp/**"

# 필터 파일로 복잡한 규칙 관리
rclone sync /home/user/data gdrive:backup --filter-from /etc/rclone/filters.txt

필터 파일 예시 Filter file example

# /etc/rclone/filters.txt
- *.tmp        # .tmp 파일 제외 (exclude)
- .DS_Store    # macOS 메타파일 제외
- __pycache__/ # Python 캐시 제외
+ **           # 나머지 전부 포함 (include all)

6. 자동화 - cron 등록 Automation with cron

로그 디렉토리 준비 Prepare log directory

sudo mkdir -p /var/log/rclone
sudo chown $USER:$USER /var/log/rclone

crontab 등록 Add to crontab

# crontab 편집 열기
crontab -e
# 매일 새벽 2시에 동기화 실행
# Run sync every day at 2:00 AM
0 2 * * * rclone sync /home/user/data gdrive:backup \
  --log-file=/var/log/rclone/sync.log \
  --log-level=INFO \
  --transfers=4 \
  --bwlimit=10M 2>&1

# 6시간마다 실행 (매일 0, 6, 12, 18시)
# Run every 6 hours
0 */6 * * * rclone sync /home/user/data gdrive:backup \
  --log-file=/var/log/rclone/sync.log --log-level=INFO

cron 표현식 참고 Cron expression reference

표현식 Expression 의미 Meaning
0 2 * * *매일 새벽 2시 / Daily at 2:00 AM
0 */6 * * *6시간마다 / Every 6 hours
0 2 * * 0매주 일요일 새벽 2시 / Every Sunday at 2:00 AM
*/30 * * * *30분마다 / Every 30 minutes

systemd 타이머 사용 (권장) Using systemd timer (recommended)

systemd 타이머는 cron보다 로깅·의존성 관리가 용이합니다. systemd timers offer better logging and dependency management than cron.

# /etc/systemd/system/rclone-sync.service
[Unit]
Description=rclone Google Drive Sync
After=network-online.target
Wants=network-online.target

[Service]
Type=oneshot
User=your_username
ExecStart=rclone sync /home/user/data gdrive:backup \
  --log-file=/var/log/rclone/sync.log \
  --log-level=INFO \
  --transfers=4

[Install]
WantedBy=multi-user.target
# /etc/systemd/system/rclone-sync.timer
[Unit]
Description=Run rclone sync daily

[Timer]
OnCalendar=*-*-* 02:00:00
Persistent=true

[Install]
WantedBy=timers.target
# 타이머 활성화 및 시작
sudo systemctl daemon-reload
sudo systemctl enable --now rclone-sync.timer

# 상태 확인
sudo systemctl status rclone-sync.timer
sudo journalctl -u rclone-sync.service -f

7. 서비스 계정 사용 (헤드리스 권장) Service Account — Recommended for Headless Servers

개인 OAuth 토큰은 주기적으로 만료되어 갱신이 필요합니다. 서버에서의 무인 자동화에는 Google Service Account를 사용하는 것이 안정적입니다. Personal OAuth tokens expire periodically. For unattended server automation, using a Google Service Account is more reliable.

STEP 1

Google Cloud Console에서 서비스 계정 생성

  1. Google Cloud Console 접속
  2. 프로젝트 선택 또는 새 프로젝트 생성
  3. IAM 및 관리자 → 서비스 계정 메뉴로 이동
  4. 서비스 계정 생성 후 키 추가 → JSON 형식으로 키 파일 다운로드
  5. Google Drive API 활성화 (APIs & Services → Library)
STEP 2

키 파일을 서버에 배포 Deploy key file to server

# 키 파일을 서버의 안전한 위치에 복사
sudo mkdir -p /etc/rclone
sudo cp service-account-key.json /etc/rclone/gdrive-sa.json
sudo chmod 600 /etc/rclone/gdrive-sa.json
STEP 3

rclone 설정에서 서비스 계정 지정 Specify service account in rclone config

# ~/.config/rclone/rclone.conf
[gdrive]
type = drive
scope = drive
service_account_file = /etc/rclone/gdrive-sa.json
Google Drive 폴더 공유: 서비스 계정 이메일(xxx@project.iam.gserviceaccount.com)에게 동기화 대상 Google Drive 폴더의 편집 권한을 부여해야 합니다.
Share the target Google Drive folder with the service account email address (editor permission).

8. 유용한 옵션 Useful Options

옵션 Option 설명 Description 예시 Example
--transfers N 동시 전송 파일 수 Parallel transfers --transfers 4
--bwlimit RATE 대역폭 제한 Bandwidth limit --bwlimit 10M
--checkers N 파일 검사 스레드 수 File check threads --checkers 8
--retries N 실패 시 재시도 횟수 Retry count on failure --retries 3
--timeout DURATION IO 타임아웃 IO timeout --timeout 60s
--drive-chunk-size 업로드 청크 크기 Upload chunk size --drive-chunk-size 256M
--backup-dir DIR 삭제 파일 백업 위치 Backup deleted files here --backup-dir gdrive:trash
--log-file FILE 로그 파일 경로 Log file path --log-file /var/log/rclone/sync.log
--log-level LEVEL 로그 레벨 Log verbosity --log-level INFO
--dry-run 모의 실행 Simulate without changes --dry-run -v

실전 권장 명령어 조합 Recommended production command

rclone sync /home/user/data gdrive:backup \
  --transfers 4 \
  --checkers 8 \
  --bwlimit 20M \
  --retries 3 \
  --drive-chunk-size 256M \
  --backup-dir gdrive:backup_trash \
  --log-file /var/log/rclone/sync.log \
  --log-level INFO \
  --progress
팁 (Tip): --backup-dir를 사용하면 sync 중 삭제되는 파일이 영구 삭제되지 않고 지정한 폴더로 이동됩니다. 안전망 역할을 합니다.
Using --backup-dir moves deleted files to a specified folder instead of permanently deleting them — a useful safety net.

9. 문제 해결 Troubleshooting

인증 토큰 만료 Auth token expired

# 토큰 재인증
rclone config reconnect gdrive:

Google Drive API 할당량 초과 Google Drive API quota exceeded

# 전송 속도와 동시 요청 수를 줄여 재시도
rclone sync /home/user/data gdrive:backup \
  --tpslimit 5 \       # API 초당 호출 수 제한
  --transfers 2        # 동시 전송 수 감소

대용량 파일 업로드 실패 Large file upload failure

# 청크 크기를 늘리고 재시도 횟수 증가
rclone sync /home/user/data gdrive:backup \
  --drive-chunk-size 512M \
  --retries 5 \
  --low-level-retries 10

동기화 상태 확인 Check sync status

# 양쪽 파일 차이 확인 (전송 없이)
rclone check /home/user/data gdrive:backup --one-way

# 마지막 로그 확인
tail -100 /var/log/rclone/sync.log

설정 파일 위치 확인 Config file location

# 설정 파일 경로 출력
rclone config file
# 일반적으로: ~/.config/rclone/rclone.conf
